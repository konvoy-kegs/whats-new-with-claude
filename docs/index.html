v2.1.321 — Fable 5.2, MCP OAuth secret-leak fix, sandbox and deny-rule fixes, mods without prompts Tue 10 Nov AEDT · 118 bullets · latest

model Added Claude Fable 5.2 (claude-fable-5-2), now the default Fable model — 1M context, $8/$40 per Mtok with $0.20/Mtok cache reads. Changed saved Fable 5.1 model picks to move to fable: on Pro and Max at once, on Team and Enterprise once your organization allows it; /model claude-fable-5-1 switches back. Fast-mode labels in /fast, /config and /model now name your current model when it supports fast mode. The /model picker's "More models" row is now unnumbered below every other. Fixed the "Draws from usage credits" note showing after a switch to Fable on Enterprise seats whose plan includes Fable.
security fixes Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them. Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt. Fixed Bash permission checks judging a file write from the wrong folder and not prompting. Fixed deny rules and protected-file prompts not applying to the file that a cp or mv into a directory writes; cp/mv spelled by path (/bin/cp) now get the same checks. Fixed sign-in, token refresh and logout hanging when something on the network accepts the connection but never answers the TLS handshake. Gateway error messages no longer show a user name or password in the gateway's address.
permission model changes Changed mods Claude writes to turn on without asking in auto and bypass modes, even with managed allowUnsandboxedCommands: false or allowManagedDomainsOnly, and not to load in dontAsk mode. Changed mods' own tool calls ($.tool.call, $.mcp.call) to raise no permission prompt, even under your own ask rules or in dontAsk and -p runs — deny rules and organization policy still apply. Remote Control sessions now keep the folder they were started in. Claude in Chrome tools provided by an app (e.g. Desktop's Code tab) now follow the org's Claude in Chrome policy. The account-email check now refuses only a shell command that holds your email and names a User-Agent, so scheduled runs no longer stop at its prompt. Fixed /config showing Manual as default when sessions start in auto mode.
Remote Control, gateway, plugins Added --settings <file> to claude remote-control, applying a settings file to every session it starts. Gateway: policy_mode: layered now adds managed MCP servers across every matching policy (a gateway already on it serves more after upgrade); Bedrock/Vertex/Foundry upstreams ignore ANTHROPIC_*_BASE_URL env vars — set base_url on the upstream; spend-limit resets shown in local time; fixed the gateway refusing to start on newer desktop fields. Managed extraKnownMarketplaces: a declared name can't be added from another source and is reinstalled from the declared one. Self-hosted runners refused as unneeded now exit 0.
cloud sessions, Desktop Code tab, Windows [Cowork cloud] A PostToolUse hook can no longer replace the answer to AskUserQuestion or the plan in ExitPlanMode's result. Fixed pkill/pgrep in cloud sessions matching the session's own parents; restarted cloud sessions dropping large-image messages or subagent messages; background agents reported as user-stopped after a service interruption. Desktop Code tab: a project MCP server no longer disconnects after the first message when Desktop has a same-named server; cross-session message limit raised from 10 to 20. Windows: faster startup and PATH lookup; skips relative and UNC PATH entries. Edit/NotebookEdit fixes on network paths (UNC, WSL, /net).

Models

Claude Fable 5.2 and Mythos 5.2 launched 9 Nov · Opus 4.8 fast mode removed 30 Nov (20 days; no fallback)

Current lineup and what changed

  • Fable 5.2 · new claude-fable-5-2 — launched 9 Nov; default Fable model in Claude Code 2.1.321+. 1M context; $8/$40 per Mtok (Fable 5.1 was $10/$50), $0.20/Mtok cache reads; optional fast mode up to 2.5× faster at $16/$80. Anthropic reports outputs up to 30% faster than Fable 5.1, fewer tokens at Medium effort (the Claude Code default), and about 55% fewer cyber/bio safeguard blocks. Available on all paid plans and on AWS, Google Cloud and Azure; on Enterprise it stays off until an admin enables it. Blocked cyber queries fall back to Opus 4.8, bio to Opus 5. Anthropic still recommends Opus 5.5 as the daily driver, with Fable for the hardest work or as an Advisor/Orchestrator.
  • Mythos 5.2 Same underlying model as Fable 5.2 with fewer cyber/bio safeguards; access via the Cyber or Life Sciences Verification Programs. Powers Claude Security for Enterprise customers.
  • launch offer Pro plans and standard Team seats get Fable models included in weekly limits from 9 Nov through 16 Nov 11:59 pm PT, plus one to three Fable resets depending on tenure.
  • Opus 5.5 claude-opus-5-5 — default Opus (22 Sep) and the recommended daily driver.
  • Sonnet 5.5 claude-sonnet-5-5 — default Sonnet (28 Sep).
  • Haiku 5.5 claude-haiku-5-5 — default Haiku (7 Oct); 1M context.
  • Opus 4.8 fast mode · removed 30 Nov Fast-mode requests on Opus 4.8 return an error after 30 Nov with no fallback — migrate to Opus 5.5 (or Fable 5.2 fast mode).
  • API · preserved thinking for all accounts Announced with Fable 5.2: preserved thinking now applies to all API accounts; check integrations that edit prior assistant context.

Security & evals

v2.1.321: MCP OAuth refresh-token leak on redirect, read-only Bash outside sandbox, cp/mv deny-rule gap — pin moves to 2.1.321

Today's actionable items

  • upgrade · pin v2.1.321 Move runners, auto-mode pipelines and headless claude -p jobs from 2.1.319 to 2.1.321. Documented, released on GitHub, on latest and next. Also required to use Fable 5.2.
  • MCP OAuth secrets MCP OAuth requests could send refresh tokens and other secrets to another host when a server redirected them. If you use OAuth-authenticated MCP servers you don't fully control, consider rotating those tokens after upgrading.
  • sandbox and deny rules A read-only Bash command could run outside the sandbox without a prompt; Bash checks could judge a write from the wrong folder; cp/mv into a directory bypassed deny rules and protected-file prompts. All fixed in 2.1.321.
  • mods and prompts Mods Claude writes now turn on without asking in auto and bypass modes, and their own tool calls skip permission prompts (ask rules included). Only deny rules and org policy constrain them — if ask rules are part of your control model, convert critical ones to deny.
  • Enterprise · Fable 5.2 enablement Fable 5.2 is off on Enterprise until an admin enables it; saved Fable 5.1 picks migrate to fable once the org allows it. Decide before users ask.
  • dates Today, Tue 10 Nov, 12:00 PM PT (Wed 07:00 AEDT): Unified Claude for Desktop policies with no desktopHome, even where coworkTabEnabled is false. 16 Nov: Enterprise unified default; Fable launch offer ends. 17 Nov: deprecated Desktop keys start warning. 30 Nov: Opus 4.8 fast mode removed; Enterprise Plugins page; Skills-off blocks plugins in Desktop.
