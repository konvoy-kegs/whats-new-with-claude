v2.1.280 — Opus 5.5 and a permission fix newest · aligned · hours old

Added Claude Opus 5.5 (claude-opus-5-5), now the default Opus model — 1M context, $4/$20 per Mtok with $0.20/Mtok cache reads. That is 20% below Opus 5 on input/output and 60% cheaper on cache reads. Alongside: Pro and Team Standard plans now default to Opus rather than Sonnet, matching Max, Team Premium and Enterprise. Effort levels saved before /effort went per-model no longer carry over to newly released models, and Opus 4.7, Opus 4.8 and Fable 5 no longer hold their launch-default effort over explicitly configured levels in -p, the SDK, project, managed or --settings effortLevel.
Security: writes through a symlinked path were judged by their in-tree spelling. acceptEdits, allow rules and auto mode could approve a write that actually landed outside the project via a symlink. The prompt now names where the write lands and those modes no longer approve an out-of-tree landing. Related containment: plugin marketplaces whose name imitates a reserved marketplace are now refused when added, and stop loading if already added; agent-type PermissionRequest hooks now error instead of silently doing nothing; self-hosted runner lifecycle-hook git ignores hook folders named in shared git files, and local-path / git:// remotes there need GIT_ALLOW_PROTOCOL.
Auto mode stops hammering. Auto mode no longer retries an action over and over when a safety check declines to review it (denied once, noting retry won't help), and when a safety check gives no answer, retries back off and the turn stops after ten in a row. Both were loops that burned tokens and time in unattended runs.
Gateway and proxy. Conversations with the advisor on no longer fail every turn with 400 "Input tag 'advisor_20260301'" behind a proxy or gateway that doesn't support it — the request now retries without it. Cloud and self-hosted runner sessions no longer fail with “Authentication failed” after a long overload rotated the access token. A model switch from a host app (Desktop, VS Code, SDK) mid-turn no longer causes a prompt-cache miss.
Ops and telemetry. New CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH changes the 2,048-character cap on MCP tool descriptions and server instructions. The hook_execution_complete OpenTelemetry event now carries hook output sizes and the number of oversized outputs saved to a file. Background subagents can use the LSP tool; background shell tasks no longer report benign non-zero exits (e.g. grep with no matches) as failures; private-repo marketplaces now honour git credential helpers during auto-update.
Behaviour change worth announcing: a stray y no longer confirms and a stray n no longer closes dialogs — Enter and Esc accept and cancel (bind confirm:yes/confirm:no in keybindings.json to restore). Ctrl+C/Ctrl+D pressed twice in most dialogs now closes the dialog instead of quitting. ctrl+l/cmd+k in fullscreen revert to redrawing the screen.

Models

new: Claude Opus 5.5
Claude Opus 5.5 launched 22 Sep — the first model in the Claude 5.5 family. Anthropic says it performs at the level of Fable 5.1 on most work and costs 40% less to run than Opus 5 on typical workloads. $4 / $20 per Mtok, $0.20/Mtok cache reads, 1M context. It is the first Opus to launch with Fable-5.1-class safeguards on cybersecurity, biology and distillation, which fall back to another model transparently. Available on Pro, Max, Team and Enterprise, the Claude Platform, and on AWS (Bedrock), Google Cloud and Microsoft Foundry.

Patterns worth tracking

Model launches come with big builds. v2.1.280 bundles the Opus 5.5 default with 113 other entries, including plan-default changes and keybinding behaviour. Launch-day builds are exactly where the lag rule matters most.
Permission paths keep getting tightened. Symlinked writes (280), compound-command sandbox exclusions (277), Write(path) rules never matching (275), device-managed MCP keys (273). Treat every managed control as unverified until you have watched it deny something.
Unattended loops are being bounded. Auto mode now backs off and stops after ten consecutive unanswered safety checks, and stops retrying declined reviews. Useful for CI and scheduled runs that previously spun silently.

Claude Desktop

macOS · Windows · Linux (beta)

What's new

Opus 5.5 in the model picker. The support-centre release notes list the Opus 5.5 launch on 22 Sep for Pro, Max, Team and Enterprise. Where it isn't showing yet, a Desktop restart picks up the new bundled CLI (v2.1.280) and model list.

Claude Cowork

GA · macOS & Windows · Linux beta

What's new

Opus 5.5 available in Cowork on paid plans from 22 Sep. At 40% below Opus 5's typical running cost it is the obvious default for long-running scheduled tasks.
Memory write conflicts in Cowork fixed (v2.1.280). For memory files over ~10,800 characters, Claude only saw the start and end on a conflict, so the retried write dropped the middle. Worth checking any large memory files for missing content.
Artifacts and routines. The Artifact tool no longer silently disappears when org policy can't load (e.g. behind a web proxy) — Claude says what's blocking it; artifact republishes that would reset stored database access rules or drop viewer profile scope are now refused; Claude now tells you when it cannot read an artifact link. Claude Tag threads get Slack's native Working indicator and Stop button, and scheduled routines no longer silently fail in workspaces connected before joining an Enterprise Grid.
Standing context. Merged Chat-and-Cowork experience (Pro/Max first; see Claude Cowork and chat are one Claude); Enterprise skill and plugin security scanning (6 Aug); account skills and plugins sync to terminal sessions (v2.1.275).
