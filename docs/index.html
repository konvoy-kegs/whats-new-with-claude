All sources aligned on v2.1.325. The newest version on npm is v2.1.325, published 2026-11-13 20:07 UTC (Sat 14 Nov 07:07 AEDT); latest and next both point at it, the changelog's top entry is v2.1.325 (139 bullets) and the GitHub release is v2.1.325 (20:40 UTC). Nothing newer has shipped since Friday's digest except this one. claude update pulls this version. Claude Desktop v5.11492.5 (13 Nov) bundles it.
What matters this morning. (1) Sandboxed Bash now asks first. 2.1.325 changes sandboxed Bash to follow the normal permission flow by default. Runners, /loop and scheduled jobs that relied on the sandbox auto-allowing commands will stall at a prompt — set sandbox.autoAllowBashIfSandboxed: true (in your highest-ranking managed source if managed settings enable the sandbox). (2) More unattended-run gotchas. Scheduled tasks and /loop now ask before running a skill that declares allowed-tools or hooks (add Skill(name) to permissions.allow); read-only git in an untrusted repo now asks (use --add-dir); "Always allow" in Desktop/IDE/SDK hosts no longer always saves a rule. (3) Security fixes worth the upgrade. zstd response-decoding security issue; compound Bash commands that could run without asking; a Bash allow rule that could run a different program than it names; sandbox gaps around worktree settings, hooks and the shared git folder; Bedrock token counting ignoring allowedProviders.

v2.1.325 — sandbox prompts by default, permission hardening, auth fixes Sat 14 Nov AEDT · 139 bullets · latest

breaking · sandbox Sandboxed Bash commands now follow the normal permission flow by default. Set sandbox.autoAllowBashIfSandboxed: true to keep running them without prompts. The sandbox also now refuses writes to .claude settings, skills, agents, commands and hooks in added directories.
security Fixed a security issue in zstd-compressed response decoding; a gap where some compound Bash commands ran without asking; a Bash allow rule that could run a different program than the one it names; some deny/ask rules not applying to certain Bash commands; relative deny rules like Read(./.env) no longer covering the project after a cd; sandbox gaps around a worktree's settings, hooks and shared git folder; sandboxed writes to the native updater's download folder.
credentials & billing Background sessions on a claude.ai login no longer use (and bill) an API key from the shell that started the background service; Bedrock token counting no longer sends the conversation to Bedrock when allowedProviders disallows it; sandbox helper programs, ripgrep and git now run without sign-in tokens or the mTLS key passphrase in their environment.
unattended runs Scheduled tasks and /loop now ask before running a skill that declares allowed-tools or hooks; read-only git commands ask in repos that aren't the project's or trusted; claude remote-control now exits 4 when it stops by itself and 69 when it can't register, so a service manager can restart it.
plugins pluginDigests is deprecated and ignored — managed remote-marketplace plugins listed in prependPlugins/appendPlugins now count as the organization's; plugin loading skips unsafe paths and links; plugin MCP bundles (.mcpb, .dxt) unpack under the plugins directory.
ops Sessions on third-party gateways and Foundry now compact instead of failing on context length every turn; CLAUDE_CODE_MAX_CONTEXT_TOKENS now also sets the window for unknown claude-* model IDs; subagents with their own model no longer get moved to the plan-mode model under opusplan; AWS credential_process and GCP default credentials work without HOME.

Security & evals

2.1.325 is the new minimum — but check sandbox prompting before rolling to runners

Today's actionable items

  • upgrade · pin v2.1.325 Move runners, auto-mode pipelines and headless claude -p jobs to 2.1.325 for the zstd, compound-Bash, allow-rule and worktree-sandbox fixes — and in the same change add sandbox.autoAllowBashIfSandboxed: true where unattended jobs relied on sandbox auto-allow, or they will hang at prompts.
  • scheduled tasks Skills that declare allowed-tools or hooks now prompt under scheduled tasks and /loop. Add Skill(name) to permissions.allow for the ones you trust to run unattended.
  • plugins If managed settings use pluginDigests, it is now ignored. Move org plugins to prependPlugins/appendPlugins.
  • certificates · Desktop 3P Under a company CA that restricts DNS names, gateway certificates with only IP addresses are now refused. Check internal gateway certs list an allowed DNS name.
  • dates 16 Nov PT: Fable launch offer ends. 17 Nov: deprecated Desktop keys start warning. 30 Nov: Opus 4.8 fast mode removed; Plugins page reaches Enterprise and turning off Skills also blocks plugins in Cowork. On/after 9 Dec: Microsoft 365 write-tool confirmation limit lifted.
