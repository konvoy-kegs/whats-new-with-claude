v2.1.283 — control which models your fleet can use newest · aligned

Model allow/deny lists that hold. New managed setting deniedModels blocks specific models even when availableModels allows them. availableModelsMatch: "exact" makes an availableModels entry allow only the exact version named, so a new release stays blocked until you add it.
New: /doctor prompt-audit (also /checkup prompt-audit) audits CLAUDE.md files, skills, agents and commands for prompting patterns written for older models. Stale paths, stale commands and contradicting instruction files lead the report.
Gateway additions. A mantle upstream provider for Amazon Bedrock's Mantle endpoint; an opt-in load_test_mode that builds and signs requests without sending them upstream; and an x-claude-code-prompt-id hint header (opt in with CLAUDE_CODE_GATEWAY_HINT_HEADERS=1) so gateways can group requests per user prompt.
Auto mode default widens. Interactive sessions on third-party providers, or with telemetry off, now start in auto mode when no permission mode is configured. Set permissions.defaultMode in managed settings if you want something else.
MCP and plugin reliability. A brief 404 from a stateless remote MCP server (e.g. a proxy mid-redeploy) no longer leaves it dead for the session; stdio servers are cleaned up on exit; claude mcp add/remove no longer reports success when the config can't be written. claude plugin validate is stricter, and installed_plugins.json is no longer rewritten with lost records.
Worth announcing. /context now counts MCP server instructions. MCP tool images are saved to a file so Bash and Read can open them. /ultrareview now warns it may upload uncommitted changes. Claude Tag gains a "Channels Claude can search" admin setting. Code Review no longer bills for reviews that timed out with nothing verified.

v2.1.282 — admin policy that actually sticks Fri 25 Sep

Mistyped boolean lock keys and single bad nested values no longer void managed permissions/autoMode blocks; project/local settings can't enable OpenTelemetry export; repo skills can't pre-approve tools under allowManagedPermissionRulesOnly. The claude-ai namespace reservation from this release is reverted in v2.1.283 (anthropic-skills stays reserved).

v2.1.280 — Opus 5.5 Tue 22 Sep

Opus 5.5 (claude-opus-5-5) is the default Opus model — 1M context, $4 / $20 per Mtok, $0.20/Mtok cache reads. Pro and Team Standard plans default to Opus instead of Sonnet.

Security & evals

model governance · Windows fix

Today's actionable items

  • pin Suggested: move the canary from v2.1.282 to v2.1.283. It carries 282's managed-settings fixes plus the sandbox fail-closed fix and the Windows delete fix. Run claude doctor on a canary before fleet rollout.
  • models Lock the model list. Consider availableModelsMatch: "exact" plus deniedModels in managed settings so new model releases (and their cost) don't reach the fleet until you approve them.
  • sandbox Managed sandbox settings were ignored entirely when one nested value was invalid (fixed in v2.1.283). The bad value now fails closed and the rest applies.
  • Windows The PowerShell tool let cmd /c rd, rmdir, del or erase delete drive roots and the home folder that Remove-Item refuses (fixed in v2.1.283).
  • auto mode Third-party-provider or telemetry-off sessions now default to auto mode when no permission mode is set. Set permissions.defaultMode explicitly for Bedrock/gateway users.
  • telemetry OTEL_LOG_TOOL_CONTENT=1 now also exports MCP, WebFetch and WebSearch outputs in tool.output spans. Check what your collector retains.
  • skills Skill(anthropic-skills:<name>) deny rules now also block the skill when Claude Desktop delivers it as a plugin. The claude-ai reservation from v2.1.282 is reverted.
  • deadline Enterprise skill/plugin scanning defaults to "Requires review" on Fri 2 Oct if no setting is chosen.

Patterns worth tracking

Fail-closed, fourth build running. 280–283 each close a path where permissions, policy or sandbox settings silently didn't apply.
Admins get model gates. With a new model roughly every few weeks, exact-match allow lists and deny lists turn model rollout into a change you approve.
The gateway keeps growing. Mantle upstream and load-test mode (283) follow readiness grace (282) and Bedrock IAM roles and guardrails (281).

No new Desktop-specific release notes since 22 Sep. From v2.1.283: Skill(anthropic-skills:<name>) denies now apply when Desktop delivers the skill as a plugin, and Remote Control works on paid plans with telemetry turned off.

Claude Cowork

GA · macOS & Windows · Linux beta · web & mobile

What's new

New 25 Sep: plugin developer portal. You can now submit plugins to the Claude directory, track them through review, and see usage analytics once they're live. See Build plugins for Claude. Relevant if we want to publish the Konvoy Cloud plugin more widely.
Heads-up: skill and plugin scanning default changes Fri 2 Oct. For Enterprise plans that haven't chosen a setting, publishing third-party skills and plugins switches to "Requires review". See Get started with skill and plugin scanning.
Routines and cloud sessions (v2.1.283). New routine schedules default to a few minutes past the hour (on-the-hour runs can start late); cloud sessions no longer redo finished steps like a duplicate push after a server restart; private repos you can read but not push to now attach read-only.
Standing context. Opus 5.5 (22 Sep); Cowork in every conversation (16 Sep, rolling out to Pro/Max); Salesforce in Claude plugin (beta, 15 Sep); smart reports for Enterprise (beta, 10 Sep); memory across chat and Cowork (25 Aug).
