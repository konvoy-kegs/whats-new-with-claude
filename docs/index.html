v2.1.284 — Sonnet 5.5 lands, auto mode everywhere newest · aligned

model Claude Sonnet 5.5 (claude-sonnet-5-5) is now the default Sonnet on the Anthropic API — 1M context, $2 / $10 per Mtok, $0.20/Mtok cache reads.
breaking default Auto mode by default, everywhere. Interactive terminal and VS Code sessions now start in auto mode when no permission mode is configured, on every plan and provider (283 did this only for third-party providers / telemetry off). permissions.defaultMode still overrides it.
gateway Claude apps gateway spend in dollars. /usage and the status line show e.g. "$271.40 / $500.00 spent this month"; rate_limits.spend_limit gains used_usd, limit_usd, period. Also new: startup warnings when availableModels is empty or omits the start model, auth: { google: {} } for telemetry forwarding to Google Cloud OTLP, private_key_jwt certificate auth to the IdP, and request headers up to 256 KiB (fixes 431s for users in many IdP groups).
feat Quality of life. /mcp reconnect all retries every failed MCP server at once; auto mode's outside-workdir read prompt gains "Yes, but ask again next time"; Ultracode becomes its own toggle in /effort and no longer forces xhigh effort.
reliability Fewer broken turns. Damaged response streams and overloaded errors after a thinking block are now retried; "Prompt is too long" after compaction triggers a second compaction; resumed sessions wait up to 10s for a still-connecting MCP server instead of "No such tool available".

v2.1.283 — control which models your fleet can use Sat 26 Sep

New managed settings deniedModels and availableModelsMatch: "exact"; /doctor prompt-audit; gateway mantle upstream and load_test_mode; managed sandbox blocks now fail closed; Windows PowerShell could delete drive roots via cmd /c rd (fixed).

v2.1.282 — admin policy that actually sticks Fri 25 Sep

Mistyped lock keys and single bad nested values no longer void managed permissions/autoMode blocks; project/local settings can't enable OpenTelemetry export; repo skills can't pre-approve tools under allowManagedPermissionRulesOnly.

Models

Sonnet 5.5 · launched 28 Sep
Claude Sonnet 5.5 launched 28 Sep — second model in the 5.5 family, a faster, cheaper complement to Opus 5.5. Anthropic says it runs 30%+ faster than Sonnet 5 and costs up to 30% less for most work; it scores 70.6% on Terminal-Bench 4.0. $2 / $10 per Mtok, 1M context. Haiku 5.5 is due "in the coming weeks".

  • Opus 5.5 claude-opus-5-5 — default Opus since v2.1.280 (22 Sep). $4 / $20 per Mtok.
  • Fable 5.1 claude-fable-5-1 — announced 1 Sep; top tier.
  • Opus 5 / Sonnet 5 claude-opus-5, claude-sonnet-5 — superseded as defaults.

  • governance If you adopted availableModelsMatch: "exact" from v2.1.283, Sonnet 5.5 stays blocked until you add it. v2.1.284 warns at gateway startup when the start model isn't in availableModels.

Security & evals

auto mode default · plugin pre-approval

Today's actionable items

  • auto mode Auto mode is now the default on every plan and provider when no permission mode is set. If that isn't what you want for the fleet, set permissions.defaultMode in managed settings before rolling out v2.1.284.
  • plugins Plugins from marketplaces, claude.ai and npm could pre-approve their own tools via allowed-tools under allowManagedPermissionRulesOnly (fixed). Only official Anthropic or managed-vouched sources keep pre-approval.
  • rules Rules symlinked into .claude/rules from outside the project now trigger the external-imports approval prompt instead of being silently skipped.
  • memory Invisible characters and tags imitating Claude Code markup are neutralised in MEMORY.md and recalled notes — a prompt-injection hardening.
  • Foundry ANTHROPIC_FOUNDRY_RESOURCE was interpolated into the endpoint host unvalidated; non-plain values are now refused.
  • models Decide on Sonnet 5.5 for the fleet: add it to availableModels if you use exact matching, or add to deniedModels to hold it.
  • pin stable moved to v2.1.277. Suggested canary: v2.1.284 (carries 282–283 fail-closed fixes plus the plugin pre-approval fix).
  • deadline Enterprise skill/plugin scanning defaults to "Requires review" on Fri 2 Oct if no setting is chosen.

Patterns worth tracking

Fail-closed, fifth build running. 280–284 each close a path where permissions, policy or plugin trust silently didn't apply.
Auto mode is becoming the norm. 283 defaulted it for third-party providers; 284 extends it to everyone. Explicit defaultMode in managed settings is now the only way to guarantee a different posture.
The gateway keeps growing. Dollar spend limits, Google OTLP forwarding and cert-based IdP auth (284) follow Mantle and load-test mode (283).
