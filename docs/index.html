Claude Code

CLI · v2.1.326 on npm latest and next · stable on v2.1.311
All sources aligned on v2.1.326. The newest version on npm is v2.1.326, published 2026-11-16 18:43 UTC (Tue 17 Nov 05:43 AEDT); latest and next both point at it, the changelog's top entry is v2.1.326 (367 bullets) and the GitHub release is v2.1.326 (22:11 UTC). claude update pulls this version. No Claude Desktop build bundling it has been announced yet (Desktop v5.11492.5 bundles 2.1.325).
What matters this morning. (1) Bypass mode is no longer a blanket pass. 2.1.326 makes some tool calls in bypass-permissions mode ask for approval, or be denied where no one can be asked; the PowerShell tool asks about (and sometimes refuses) more commands even in bypass mode; the Bash sandbox now asks before some environment-variable lines when auto-allow is off. Headless runners and claude -p jobs can start refusing work — test before rolling out and add explicit allow rules. (2) Credential hardening. Claude's file tools now refuse writes to Claude Code's sign-in files (e.g. .credentials.json), Bash asks before more commands touch them, and sandboxed commands no longer write to some sensitive home folders (re-allow with sandbox.filesystem.allowWrite). (3) Ops fixes. Background sessions that lose their exported LLM gateway now stop before any model request instead of falling back; managed subagent model now applies in Desktop's Code tab; compaction fixed on Bedrock, Vertex and Foundry.

v2.1.326 — bypass-mode tightening, credential protection, background-session fixes Tue 17 Nov AEDT · 367 bullets · latest

behaviour change · permissions Some tool calls in bypass-permissions mode now ask for approval, or are denied where no one can be asked. The PowerShell tool asks before (and sometimes refuses) more commands, even in bypass mode — unattended runs refuse them unless an allow rule, auto mode or bypass allows them. Bash asks about some commands with very long values it can't finish checking, and the sandbox asks before some env-var lines when auto-allow is off.
security · credentials Claude's file tools now refuse writes to Claude Code's sign-in files such as .credentials.json; Bash asks before more commands reach them. Sandboxed commands on macOS, Linux and WSL no longer write to some sensitive home folders by default (sandbox.filesystem.allowWrite to re-allow); unexpected entries in a repo's .git folder are set aside after sandboxed commands; commands rewritten by a permission hook or SDK host stay sandboxed unless the approver sets dangerouslyDisableSandbox: true.
security · ops Fixed the background service ending other users' processes (e.g. an SSH login) when a reused PID was on its list; fixed claude purge hiding its prompts when stdout is redirected (one unseen Enter could delete a project's data); fixed managed PreToolUse hook refusals leaving no OTel tool_decision event; settings nested past 64 levels are now dropped with a warning instead of crashing.
features Code Mode can now run with agent teams enabled; OTEL_RESOURCE_INCLUDE_HOST adds host.name/host.id to OTel resource attributes; /status shows when a provider or env var such as DISABLE_TELEMETRY turns features off; startup warning for incomplete --allowedTools/--disallowedTools entries; a message explains why MCP servers stop loading when an admin adds managed-mcp.json mid-session.
gateways & providers Background sessions that lose the LLM gateway your shell exported now stop before any model request; compaction fixed on Bedrock, Vertex and Foundry; image-heavy Vertex sessions no longer stick on the 30 MB request limit; requests exceeding a model's max_tokens now retry with the API-reported maximum; Desktop Code tab now retries a one-off 401 and honours the managed subagent model.
quality of life /update-config uses ~13k tokens of context instead of 93k; CPU use improved with 20+ subagents; /model "Default" now names your plan's default model; many /rewind, /login and resume-after-crash fixes.

Security & evals

2.1.326 is the new minimum — but test bypass-mode runners first

Today's actionable items

  • upgrade · pin v2.1.326 Move runners, auto-mode pipelines and headless claude -p jobs to 2.1.326 for the credential-file protection and sandbox hardening — but run one job first: bypass-permissions mode and the PowerShell tool now ask or refuse some calls, so unattended jobs may fail rather than hang. Add explicit permissions.allow rules for what they need.
  • sandbox Carry forward 2.1.325's sandbox.autoAllowBashIfSandboxed: true where needed. If jobs write to home-folder paths (tool caches, config dirs), check for new refusals and add sandbox.filesystem.allowWrite entries.
  • observability Set OTEL_RESOURCE_INCLUDE_HOST=1 on shared runners if you want per-host attribution in Grafana; managed PreToolUse refusals now emit tool_decision events.
  • plugins If managed settings use pluginDigests, it is ignored since 2.1.325. Move org plugins to prependPlugins/appendPlugins.
  • dates Today ~18:59 AEDT: Fable launch offer ends. 17 Nov: deprecated Desktop keys start warning. 30 Nov: Opus 4.8 fast mode removed; Plugins page reaches Enterprise and turning off Skills also blocks plugins in Cowork. On/after 9 Dec: Microsoft 365 write-tool confirmation limit lifted.
