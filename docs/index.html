v2.1.293 — Claude Haiku 5.5, compaction & MCP fixes newest · aligned

model Added Claude Haiku 5.5 (claude-haiku-5-5), now the default Haiku model on the Anthropic API — 1M context, $0.10/$0.50 per Mtok ($0.50/$2.50 for prompts over 100K). Per the permission-modes docs, Haiku 5.5 qualifies for auto mode, and on Bedrock, Google Cloud and Foundry that needs Claude Code 2.1.293+.
reliability Fixed Claude sometimes treating its own last actions before a context compaction as done after it, and retracting or redoing finished work. Fixed a memory leak where an HTTP MCP connection kept every request it had sent until it closed. Path-scoped rules and nested CLAUDE.md files now load when Claude views a file via cat/head/tail/sed -n/grep in Bash. /model effort no longer wraps past High/Low (which could save Low as a default). Windows: stopping a status line, hook or shell command no longer risks terminating an unrelated process that reused the PID.
permissions & auth claude agents now asks for bypass-permissions consent first when it was only saved in .claude/settings.local.json or a --settings file (background sessions were ignoring it). Subagents are no longer told to use SendMessage when a host, permission rule or --tools list removed it. claude logs/stop/kill/rm and claude daemon commands no longer sign you out when your login is near expiry.
reverts & changes Reverted the 2.1.281 auto-mode denial message change, and the 2.1.290 fix that told Claude when a cloud container restart lost a pending /loop wakeup (sessions now stay asleep). Team/Enterprise startup fetches policy and managed settings earlier, retrying after 3 s. claude.ai skill sync now checks every ~40 min (was 10) while idle. OpenTelemetry claude_code.at_mention capped at 100 agent + 100 MCP-resource events per prompt. New agentType in the subagentStatusLine payload; isDeferred on $.tool.register for mods.
Claude Tag · Code Review Claude in Slack no longer stops mid-task when an admin changes a channel's connectors/plugins/skills/rules (applies after it finishes); fixed Enterprise Grid shared-channel "not set up" errors; channel rules limit raised from 20 to 50. Code Review's Add a repository dialog now lists each repo that couldn't be added and why.

v2.1.292 — security sweep, plugin install shortcut, MCP protocol bump Tue 6 Oct UTC

permissions PreToolUse hook approvals and auto mode could bypass the permission prompt for UNC-path file reads; a tampered on-disk managed-settings cache could unseat the built-in policy plugin; sandboxed commands could read staged /ultrareview uploads; managed read-deny paths appearing mid-session didn't drop grants; Windows 8.3 short-name rm -rf of home/drive wasn't treated as destructive — all fixed.
workflow claude plugin install --marketplace <source>; Agent tool effort parameter; CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS; NO_PROXY honoured for Claude Code's own requests; stdio MCP servers negotiate protocol 2026-07-28 by default (MCP_PROTOCOL_NEGOTIATION=legacy opts out).

v2.1.291 — two regression fixes Mon 6 Oct UTC

regressions Cloud sessions could drop answers to permission prompts (from 2.1.290); the last messages of a session could be lost when quitting (from 2.1.288).

v2.1.290 — permission & policy hardening Mon 5 Oct UTC

permissions Bash checks stop auto-approving wildcard-expanding "read-only" commands; rules apply after a PreToolUse hook rewrites input; background workers no longer honour --allow-dangerously-skip-permissions without the disclaimer. claude attach/claude logs <name>, managed-settings doctor warnings, WebSearch refills at 100 calls/hour.

Security & evals

quieter day · 2.1.292 remains the key security upgrade

Today's actionable items

  • fleet Move to 2.1.293. It carries all of 2.1.292's security fixes (UNC-path reads, tampered managed-settings cache, sandbox read-deny, Windows 8.3 rm -rf) plus the HTTP MCP memory leak fix.
  • background agents If you rely on bypass-permissions for claude agents via .claude/settings.local.json or --settings, expect a consent prompt now — previously background sessions silently ignored it.
  • 3P clouds Teams wanting Haiku 5.5 in auto mode on Bedrock / Google Cloud / Foundry need 2.1.293+. Check model allow-lists and gateway routing for claude-haiku-5-5.
  • MCP protocol stdio MCP servers negotiate 2026-07-28 by default since 2.1.292; smoke-test internal servers. MCP_PROTOCOL_NEGOTIATION=legacy is the escape hatch.
  • Desktop admin The 7 Oct deadline for deprecated managed-config key spellings (incl. inferenceGatewayAuthScheme: "sso") has passed. Confirm managed configs use the current keys.

Patterns worth tracking

Reverts are back. 2.1.293 reverts two earlier changes (2.1.281 auto-mode denial wording; 2.1.290 cloud /loop wakeup notice). If you depended on either behaviour, re-test.
stable keeps falling behind. Eight releases now separate stable (2.1.285) from latest, including four permission-hardening releases. Pin to latest-track versions on managed machines.

Claude Cowork

GA · macOS, Windows & Linux · web & mobile · cloud by default on Pro/Max

What's new

Cloud by default (since 6 Oct) on Pro and Max. New tasks run in the cloud on every surface; "Only on your computer" was removed and local-only users are moved to the cloud on next launch. See Use Claude Cowork on web, desktop, and mobile.
Cloud sessions & routines (Claude Code 2.1.292–2.1.293). Scheduled and Run-now routines publish a private artifact without an approval prompt; routine runs no longer sit "running" for hours. Note: 2.1.293 reverts the notice telling Claude a container restart lost a pending /loop wakeup — such sessions now stay asleep, so check long-running scheduled loops.
Plugins. claude plugin install --marketplace <source> (2.1.292) adds and installs in one step under org policy checks. Plugin developer portal for the Claude directory open since 25 Sep; Cowork and chat merged into one Claude experience since 16 Sep.
