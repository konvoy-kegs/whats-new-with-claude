v2.1.281 — gateway controls and a hardening sweep newest · aligned · hours old

Claude apps gateway on Bedrock. New assume_role on Bedrock upstreams: the gateway calls Bedrock as an IAM role via STS, cross-account if needed, optionally one session per developer. New guardrail: {id, version} applies an Amazon Bedrock guardrail to every request (set it on all Bedrock upstreams or none). telemetry.resource_attributes adds fixed labels to Desktop and /login telemetry.
Desktop policy through the gateway. desktop policy blocks now accept newer Claude Desktop keys, including blockReadsOutsideWorkingDirectories and disableBypassPermissionsMode.
Permissions and sandbox tightened. A recursive rm whose target is only command-substitution output (e.g. rm -rf "$(pwd)") no longer runs unprompted in auto or --dangerously-skip-permissions mode, even with a Bash allow rule. A permission rule containing a NUL byte no longer expands into a wildcard. claude --bg now asks for workspace trust before running project hooks. --setting-sources / SDK settingSources now carry to spawned sessions (teammates, /bg, --worktree --tmux).
Proxy and gateway resilience. Streams cut short by a proxy are no longer shown as complete; tool calls no longer run twice on duplicated stream events; "Content block not found" keeps the partial response; CLAUDE_CODE_RETRY_WATCHDOG no longer fails after runs of 429/529; HTML error pages from proxies no longer dump raw markup.
Resume and prompt cache. Resumed sessions no longer re-send earlier turns in a changed form, very large sessions resume fully, and the cache survives an MCP server disconnect when tool search is off (common behind gateways).
Worth announcing. "attribution": false in settings.json hides all commit and PR attribution (older CLIs skip a settings file that holds it — keep the object form in shared files). claude plugin validate now checks MCP entries that would be silently dropped and insecure URLs. /insights estimates how many prompts auto mode could have handled.

v2.1.280 — Opus 5.5 Tue 22 Sep

Opus 5.5 (claude-opus-5-5) is the default Opus model — 1M context, $4 / $20 per Mtok, $0.20/Mtok cache reads. Pro and Team Standard plans now default to Opus instead of Sonnet. Effort levels saved before /effort became per-model no longer apply to newly released models. New CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH; hook output sizes added to hook_execution_complete telemetry; marketplaces imitating a reserved name are refused.

Patterns worth tracking

Model launches are followed by large hardening builds. v2.1.280 shipped Opus 5.5; v2.1.281 a day later is almost entirely fixes.
Permission paths keep getting tightened. Command-substitution rm and NUL-byte rules (2.1.281), symlinked writes (280), compound-command sandbox exclusions (277).
The gateway is becoming the control plane. Desktop policy keys, Bedrock IAM roles and guardrails, telemetry labels — all in the gateway config now.

Claude Desktop

macOS · Windows · Linux (beta)

What's new

Admin policy via the Claude apps gateway. Claude Code v2.1.281 lets gateway desktop policy blocks set newer Desktop keys, including blockReadsOutsideWorkingDirectories and disableBypassPermissionsMode; telemetry.resource_attributes labels Desktop telemetry.
Code sessions from Desktop. Faster resume of long compacted sessions opened in Desktop; the Artifact tool is back in Remote Control sessions opened from Desktop, claude.ai or mobile; sign-in and usage-limit errors now point at the app rather than terminal commands.
Opus 5.5 in the model picker since 22 Sep. Standing context: artifacts created on or after 19 Aug are shareable and open on web and Desktop.
