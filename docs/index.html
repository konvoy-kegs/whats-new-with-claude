v2.1.289 — deny/ask rules hold in more places newest · aligned

permissions Bash deny/ask rules no longer slip under sandbox auto-allow when the command has an env-var prefix with an expanded value (e.g. TZ="$HOME" rm -rf build) or a bare variable assignment before it. A deny/ask rule on a nested part of a compound command now also holds over a user-installed mod's approval on managed machines.
permissions Read deny rules now apply through symlinks for files @-mentioned, changed or selected in the IDE. A user-installed plugin can no longer rewrite the descriptions of an org-managed MCP server's sign-in tools.
mods Plugin/mod APIs: agent.spawn for teammates, one agent id across plugin hook events, idle/waiting states in $.agent.list(). Many stability fixes: mods not loading in the first session after upgrade, freezes from unknown Box border styles, supervised/background sessions ending on async plugin errors.
VS Code Reverted the 2.1.288 claude auth status change that may have made sign-outs more frequent — if your team saw extra sign-outs on 2.1.288, update.

v2.1.288 — rm bypass, MCP OAuth step-up, quality-of-life Fri 2 Oct UTC

permissions A dangerous rm (on / or home) inside bash -c/sh -c could run without a prompt in bypassPermissions mode or under a shell allow rule — fixed (anthropics/claude-code#96300). Also: BASHPID arithmetic assignment now prompts; sandbox.credentials.files on git config now honoured with blockReadsOutsideWorkingDirectories.
auth /login no longer reports success when credentials couldn't be saved to secure storage; /login in --bare no longer overwrites your saved login. Re-authenticate prompt when an MCP server asks for more OAuth scope mid-call.
workflow /code-review --max-findings <n>|all; Up on an empty prompt restores a draft cleared with Ctrl+C; background command time limit now applies only to unattended sessions (-p, SDK, CI, cloud); claude project purge → claude purge; auto mode compacts instead of failing when the conversation outgrows the safety classifier.
telemetry Unanswered permission asks (in -p or interrupted turns) now emit a tool_decision event — expect slightly more events in OTel pipelines.

Security & evals

permission-rule bypasses fixed in 2.1.288 & 2.1.289

Today's actionable items

  • permissions Move canaries to 2.1.289: closes Bash deny/ask bypasses via env-var prefixes and bare assignments under sandbox auto-allow, and Read deny bypass via IDE symlinks.
  • permissions 2.1.288 fixed dangerous rm inside bash -c running unprompted in bypassPermissions or under a shell allow rule.
  • supply chain User-installed plugins could rewrite descriptions of org-managed MCP sign-in tools — fixed in 2.1.289. Worth reviewing alongside the Enterprise plugin scanning default that changed on 2 Oct.
  • auth /login false-success and --bare login overwrite fixed in 2.1.288.
  • desktop Desktop v2.19675.0 drops computer use on macOS 13 and earlier; fixes sandbox proxy loss after a PAC download failure (VPN switch).
  • deadline Cowork on Pro/Max goes cloud-by-default tomorrow, Tue 6 Oct.

Patterns worth tracking

Sandbox auto-allow is a recurring edge. 2.1.288 and 2.1.289 both close cases where deny/ask rules were skipped under sandbox auto-allow. If you rely on deny rules as a guardrail, keep the fleet current.
Mods are maturing fast. Two releases of mod API additions and stability fixes since Claude Mods landed in 2.1.287, plus the first managed-machine precedence fix (deny rules beat mod approvals).

Claude Desktop

v2.19675.0 · 1 Oct · bundles Claude Code 2.1.286

What's new

Line comments in the Files pane (Code tab). Click + beside a line or select text and choose Add comment; comments go with your next message.
Reliability. Failed sends now offer Retry instead of looking sent; conversations no longer break after a connector returns an oddly shaped result; Claude can run commands in the Terminal panel on Windows again; Windows app starts when Google/Chrome folders under LocalAppData are junctions.
Admin/3P. Computer use now requires macOS 14+; 1M context default behind gateways/custom base URLs; Linux spellcheck dictionary added to Egress Requirements (skipped with disableNonessentialServices).

Claude Cowork

GA · macOS & Windows · Linux beta · web & mobile

What's new

Tomorrow (Tue 6 Oct): cloud by default. New Cowork tasks on Pro and Max will run in the cloud, and "Only on your computer" in Settings > General is being removed. See Use Claude Cowork on web, desktop, and mobile.
Scheduled tasks Claude creates now default to "Automatically approve" where the org allows it (Desktop v2.19675.0) — runs use tools without asking and pause only when something looks unsafe. Review org policy if you want scheduled runs gated.
Fixes. Corporate proxies set by a one-word host name now work; background clicking in apps like Slack is more accurate; expired sign-in requests no longer leave replies "waiting on you". Claude Code 2.1.288 also fixes cloud sessions stuck waiting after an unanswered WebFetch prompt and adds a built-in gh api to cloud images without the GitHub CLI.
