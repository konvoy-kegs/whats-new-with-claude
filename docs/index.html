Claude Code

CLI · v2.1.323 on npm latest and next · stable on v2.1.311
All sources aligned on v2.1.323. The newest version on npm is v2.1.323, published 2026-11-12 20:29 UTC (Fri 13 Nov 07:29 AEDT); latest and next both point at it, the changelog's top entry is v2.1.323 (294 bullets) and the GitHub release is v2.1.323 (22:12 UTC). claude update pulls this version.
What matters this morning. (1) Upgrade runners to 2.1.323. It closes a long list of permission gaps: Write/Edit could write to a path covered by a Read deny rule; Bash(ls*)-style allow rules and combined sudo flags could skip prompts; deny/ask rules missed commands wrapped in sudo/env; the Bash sandbox could switch off mid-session; sandbox.excludedCommands could let unnamed commands out. (2) Headless gotcha fixed. claude -p and the Agent SDK used to run Bash unsandboxed when a sandbox-enabling --settings file failed validation; it now stops at start-up. (3) Behaviour changes to check. Unknown model IDs now assume a 1M context (set CLAUDE_CODE_DISABLE_1M_CONTEXT=1 for gateways fronting smaller-window models); git worktree add/move/remove now fail read-only in the sandbox; symlinked write grants are ignored — grant the real path.

v2.1.323 — Code Mode, plugin version pinning, permission and sandbox hardening Fri 13 Nov AEDT · 294 bullets · latest

new workflow Added Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools (docs — also covers turning it off for an organization).
plugins Added engines["claude-code"] to plugin.json: plugins outside their stated Claude Code version range are not installed, updated or loaded. claude plugin validate now type-checks TypeScript hooks (--strict fails on findings). A plugin's agent setting is deprecated.
permissions & sandbox Fixed Write/Edit writing to Read-denied paths; wildcard and sudo allow-rule prompt skips; deny/ask rules missing sudo/env-wrapped commands; the Bash sandbox switching off mid-session; excludedCommands leaking unnamed commands; sandboxed commands reading checkpoint copies; --permission-mode auto starting in a more permissive mode when auto was unavailable (now Manual); plan files written outside the project; a zsh-option prompt bypass.
credentials Internal ripgrep and git now run without most sign-in tokens and API keys, so credential helpers and hooks can't see them; "don't ask again" rules that look like secrets are session-only; claude.ai/Cowork check plugin files for secret keys before sending. Many background-session sign-in fixes (sessions no longer silently move to another account).
behaviour changes Unknown model IDs now assume 1M context (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 to keep 200K); macOS/Linux sandbox makes git worktree add/move/remove read-only; symlinked write grants ignored; start-up stops on an invalid --settings file with a sandbox key; the v1 MCP client is removed (MCP_SDK_GENERATION=v1 now runs v2 in compatibility mode); subagentStatusLine removed; /security-review now asks before running.
ops Bedrock model-refused errors now say to enable the model, not refresh AWS creds; awsAuthRefresh/gcpAuthRefresh no longer double-run; managed settings read twice if being rewritten at start-up; MCP TOKEN_EXPIRED now prompts re-sign-in; 30s heartbeat for long hooks in claude -p.

Security & evals

2.1.323 is the new minimum for runners and headless jobs

Today's actionable items

  • upgrade · pin v2.1.323 Move runners, auto-mode pipelines and headless claude -p jobs to 2.1.323. The headline fix: a sandbox-enabling --settings file that failed validation left Bash unsandboxed in -p/SDK runs. Also closes Read-deny write bypass, wildcard/sudo allow-rule skips and a mid-session sandbox switch-off.
  • audit allow rules 2.1.323 adds a start-up warning for Bash allow rules with * in a variable's value (e.g. Bash(PORT=* npm run dev)), and Bash(NODE_ENV*)-style rules now prompt. Review shared settings.json files before rollout.
  • sandbox behaviour git worktree mutations and commits in other worktrees now fail read-only in the macOS/Linux sandbox; writes via symlinks are ignored. Expect breakage in scripts that relied on either.
  • gateways Unknown model IDs default to a 1M window — on gateways fronting smaller-window models, set CLAUDE_CODE_DISABLE_1M_CONTEXT=1 or sessions can fail every turn once full.
  • dates 16 Nov: Enterprise unified default on; Fable launch offer ends. 17 Nov: deprecated Desktop keys start warning. 30 Nov: Opus 4.8 fast mode removed; Plugins page reaches Enterprise, and orgs with Skills off also block plugins in Desktop.
