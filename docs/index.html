Claude Opus 5

model · launched 24 Jul

Opus 5 is out — near-Fable intelligence at half the price headline

Source: Introducing Claude Opus 5 · anthropic.com · 24 Jul 2026 · system card

claude-opus-5 is available on all platforms today. Anthropic describes it as “thoughtful and proactive,” coming close to Fable 5’s frontier intelligence at half the price. Pricing is $5 / $25 per Mtok — identical to Opus 4.8, so this is a free capability upgrade for anything already pinned to Opus. It is the new default model on Claude Max and the strongest model on Pro. New state-of-the-art on Frontier-Bench and GDPval-AA; it more than doubles Opus 4.8 on Frontier-Bench v0.1 at a lower cost per task.
What this means for us: claude update to v2.1.220 and Opus 5 becomes your default Opus in Claude Code — no config change needed. Two things to action: (1) our Bedrock/Vertex pipelines pinned to claude-opus-4-8 will not move on their own, so schedule the model-string bump deliberately rather than letting it drift; (2) /fast no longer applies to Opus 4.7 — fast mode is now Opus 5 and Opus 4.8 only, and Opus 5 fast mode bills at 2× base ($10 / $50 per Mtok) for ~2.5× the speed. Worth checking any usage-credit budgets that assumed 4.7 fast mode.
  • model Available today on all platforms as claude-opus-5 at $5 / $25 per Mtok (unchanged from Opus 4.8). Fast mode runs ~2.5× default speed at twice base price on the Claude Platform, and via usage credits in Claude Code. No data-retention requirements for general access, consistent with prior Opus models.
  • performance New SOTA on Frontier-Bench and GDPval-AA. On CursorBench 3.2 at max effort it lands within 0.5% of Fable 5’s peak at half the cost per task. ARC-AGI 3: 3× the next-best model. OSWorld 2.0 (computer use): beats Fable 5’s best result at just over a third of the cost — relevant to our Cowork computer-use work.
  • agentic behaviour The pitch is verification and follow-through on long-running work: it checks its own output and iterates. Anthropic’s examples include writing a computer-vision pipeline to read a drawing it had no way to view, and finding the root cause of an open-source bug where the community patch had only fixed the symptom. Several early-access partners specifically call out lower run-to-run variance versus Opus 4.8.
  • efficiency Multiple early-access reports of the same result at materially fewer tokens — one legal-tech partner saw comparable quality with 26% fewer tokens at max reasoning; a trading benchmark reported roughly a seventh of the reasoning tokens and under half the latency of Opus 4.8. If our spend per task drops after upgrading, this is why.
  • safeguards Cyber classifiers are ~85% less restrictive than Fable 5’s: source-code vulnerability discovery is allowed; binary-based vulnerability scanning, penetration testing, and exploit generation are blocked. Flagged requests in Claude.ai, Claude Code, and Cowork fall back to Opus 4.8 by default — so expect the occasional silent model switch on security-adjacent prompts. Enterprises in the Cyber Verification Program get a less-restricted build.
  • alignment Anthropic’s automated behavioural audit rates Opus 5 its most aligned model to date (2.3 on overall misaligned behaviour, the lowest of recent models), with the lowest rates of deceptive behaviour and the best record on avoiding hard-to-reverse actions. It does not advance the frontier on dual-use capability — it stays behind Mythos 5 on both biology research and offensive cyber, notably on exploit development even though it is close on vulnerability discovery (OSS-Fuzz).
  • API betas Two beta features shipped alongside: mid-conversation tool changes (swap Claude’s available tools mid-conversation without invalidating the prompt cache — useful for our long-running agents) and automatic server-side fallbacks (classifier-flagged requests route to another model instead of erroring).
  • routing change Biology-related requests blocked on Fable 5 now route to Opus 5 rather than Opus 4.8. Opus 5 is now Anthropic’s most capable generally available model for scientific research.

v2.1.219 — Claude Opus 5 is the new default Opus, strict sandbox network allowlist, nested subagents headline

Published 24 Jul 2026 at 16:11 UTC · CHANGELOG · the release that actually matters this week

Claude Opus 5 (claude-opus-5) is now the default Opus model — 1M context, fast mode at $10/$50 per Mtok. Opus 4.7 has been removed from fast mode; /fast now applies to Opus 5 and Opus 4.8 only. The bundled claude-api skill now defaults to Opus 5, with a documented migration path from Opus 4.8.
Two changes to look at before rolling this out. First, sandbox.network.strictAllowlist denies non-allowlisted hosts for sandboxed commands without prompting — the right default for our CI agents, but it will hard-fail any build step reaching a host we forgot to list, so stage it. Second, subagents can again spawn nested subagents, now up to depth 3 by default (v2.1.217 had cut this to 1). Combined with the 20-concurrent-subagent cap from v2.1.217 that is a much wider fan-out than last week; set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 if you want the old behaviour back on cost-sensitive runners.
  • model Added Claude Opus 5 (claude-opus-5), now the default Opus model — 1M context, fast mode at $10/$50 per Mtok. Removed Opus 4.7 from fast mode. Updated the claude-api skill to default to Opus 5 with a migration path from Opus 4.8.
  • security Added sandbox.network.strictAllowlist to deny non-allowlisted hosts for sandboxed commands without prompting.
  • subagents Subagents can now spawn nested subagents up to depth 3 by default (was 1); set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 to disable nesting. Nested subagent forwarding also works in stream-json: depth-2+ subagents appear with --forward-subagent-text, keyed by their spawning Agent tool_use id.
  • feat Added a DirectoryAdded hook that fires after /add-dir or the SDK register_repo_root control request registers a new working directory mid-session.
  • observability Added mcp_server_errors to the headless stream-json init event, listing --mcp-config entries skipped by config validation; terminal runs print a startup warning. claude mcp list and /mcp now show HTTP status and error text when a server fails to connect, and warn about MCP config values with hidden leading/trailing whitespace — useful for debugging our MCP fleet.
  • config Added the workflowSizeGuideline settings key so the advisory dynamic-workflow size guideline can be set from any settings file. Dynamic workflows now default to a medium guideline (aim for fewer than 15 agents); the running-workflow status line shows the current default.
  • managed settings Managed MCP allowlist/denylist ${VAR} entries now resolve from the startup environment and managed-settings env instead of settings-file env — check any org-managed allowlists that relied on the old resolution.
  • fix Fixed claude -p dropping an already-produced answer when a turn dies on a mid-stream API error; stale fast-mode status on Remote Control clients after a model switch or reconnect; CLAUDE_CODE_GIT_BASH_PATH on Windows being used as bash when it isn’t a bash/sh binary (now ignored with a warning); the /model picker showing “Opus” instead of “Opus (1M context)”; copy-on-select printing base64 inside GNU screen; and Vim-mode ← on an empty prompt not returning to the agent view from NORMAL mode.

v2.1.218 — /code-review as a background subagent, fewer auto-mode dialogs, agent-hook trust

Published 22 Jul 2026 at 19:55 UTC · CHANGELOG

  • workflow /code-review now runs as a background subagent, so review work no longer fills your conversation and stacked slash commands stay as its review target.
  • security Agent frontmatter hooks no longer run from untrusted folders — the agent file’s own folder must have accepted workspace trust. Trust dialogs now name the repository root the grant covers.
  • windows Fixed Windows paths with \u-prefixed segments (e.g. C:\Users\unicorn) being corrupted into CJK characters in tool inputs, which made those files inaccessible.
  • data loss Fixed the left-arrow key discarding the conversation with no undo — presses right after editing now ask to confirm.
  • auto mode The dangerous-rm, background-&, and suspicious-Windows-path checks no longer open permission dialogs; the auto-mode classifier adjudicates them. Plan mode with auto no longer prompts for Bash commands the static analyzer can’t prove read-only. /deep-research now starts only when invoked manually.
  • billing Fixed gateway spend metering to price Bedrock application-inference-profile ARNs and other config-mapped upstream model IDs at the configured model’s rates — check our Bedrock cost reporting.
  • fix Skills with context: fork now run in the background by default (opt out with background: false); agent names containing : are rejected (reserved for plugin namespacing); remote sessions no longer heartbeat forever after their worker is replaced.

Before that, self-serve HIPAA configuration (14 Jul) and the monthly recap / Reflect features (9 Jul).

Opus 5 in the model picker — and it is the new default on Max (24 Jul). If you are on Max, your Desktop conversations moved to Opus 5 automatically; on Pro it is the strongest model available. Same price as Opus 4.8. Note the classifier fallback: security-adjacent prompts that get flagged silently fall back to Opus 4.8, so if a Desktop answer looks like a different model wrote it, that is why. See Introducing Claude Opus 5.
Self-serve HIPAA configuration (14 Jul). Eligible admins can now review the Business Associate Agreement, download the implementation guide, and enable HIPAA readiness in a single flow — for both Claude Enterprise and the Claude Platform (API), no Sales conversation required. See HIPAA-ready Enterprise plans.
Monthly recap — new “Reflect” features (9 Jul). Settings → Reflect shows the topics you spent time on, your most active day and peak hour, and observations about how you work with Claude. In beta on Free, Pro, and Max on web and Claude Desktop; requires memory on. Alongside it, Settings → Time and focus adds optional break reminders and quiet hours. See See your monthly recap.
Memory is now categorised entries, not a daily summary (10 Jul). Claude reads and updates a set of individual, categorised memory entries during conversations, replacing the old daily memory summary — so corrections stick to the specific fact rather than being buried in a rolling digest. See chat search and memory.
  • feature Model entitlements for Enterprise plans (beta, 1 Jul) — admins can control which models their users can reach and which effort levels they can select. Directly relevant now that Opus 5 exposes effort settings that trade intelligence against token spend. See Manage model access for your organization.
  • feature Claude Sonnet 5 is in the Desktop model picker (30 Jun) — most agentic Sonnet yet, with substantial gains over Sonnet 4.6 in reasoning, tool use, and coding. See Introducing Claude Sonnet 5.
  • feature Trusted Devices for Remote Control (25 Jun) — Team/Enterprise admins can require members to verify their device before viewing or steering local Claude Code sessions remotely. See Trusted Devices.
  • feature Delegate work to Claude in Slack with Claude Tag (23 Jun) — tag Claude in a conversation and hand off a task; useful for our #cloud-engineers threads. See Introducing Claude Tag.
  • feature Edit Claude’s drafts in place (12 Jun) — highlight the part of a draft you want changed and type the change; Claude edits where you marked it, in chat and in Cowork. See Work with artifacts.
  • feature Single Customize directory for skills, connectors, and plugins (Settings → Customize), plus plugin marketplace and admin controls on Team and Enterprise plans.

Claude Cowork

Generally available

What's new

Sources: Get started with Claude Cowork, Schedule recurring tasks, Use plugins in Claude, Skills, connectors and plugins directory. Checked Wed 29 Jul 2026 — no Cowork-specific release note in three weeks (nothing since 7 Jul). The Opus 5 launch (24 Jul) affects Cowork model selection; the newest Cowork-specific items remain Cowork on web and mobile (7 Jul) and Microsoft 365 connector write tools (7 Jul).

Opus 5 is selectable for Cowork tasks (24 Jul). The gains that matter most here are the agentic ones — OSWorld 2.0 (computer use) beats Fable 5’s best result at just over a third of the cost, and Zapier reported a 100% pass rate on AutomationBench where previous models failed outright. For long-running and scheduled tasks like this digest, the lower run-to-run variance is the more useful property. Flagged security-adjacent requests fall back to Opus 4.8. See Introducing Claude Opus 5.
Cowork runs on web and mobile (7 Jul). Rolling out over several weeks, starting with Max. Sessions run remotely (in beta) and save to your Claude account, so work continues when you close your laptop and scheduled tasks run with no device online. Chat and Cowork now share one home, with one place for projects and artifacts across both. See Use Claude Cowork on web, desktop, and mobile.
Projects & scheduled tasks. Organise related work into persistent workspaces — each with its own files, links, instructions, and memory — and delegate recurring or on-demand work with /schedule. Scheduled tasks run remotely, so they don’t need your computer awake or the desktop app open. This morning’s digest is exactly that in action.
  • feature Microsoft 365 connector write tools (7 Jul) — with Entra admin consent, Claude can draft, send, and organise email, manage calendar events, update mailbox settings, and create or update files in OneDrive and SharePoint; Teams stays read-only. Requires both admin consent and org-level enablement. See Connect to Microsoft 365.
  • feature Plugins bundle skills, connectors, and sub-agents into one installable package, available on all paid plans. Admins can create private plugin marketplaces and set per-plugin install preferences — auto-installed, self-service, or hidden from the org catalog. Custom marketplaces can be installed from a GitHub repo. See Manage plugins for your organization.
  • feature Skills, connectors, and plugins now live in one browsable directory; type / or click + to see what your installed plugins offer, in chat and in Cowork. See Browse skills, connectors, and plugins.
  • feature Claude Sonnet 5 is available in Cowork (30 Jun) for more agentic tool use on long-running and scheduled tasks. See Introducing Claude Sonnet 5.
  • feature Computer use — Claude can click, type, open apps, and run dev tools in Cowork (research preview on Pro and Max). See Let Claude use your computer in Cowork.
  • feature Usage analytics for Cowork via the Analytics API, plus OpenTelemetry support for monitoring activity — see Monitor Cowork activity with OpenTelemetry. Role-based access controls let Enterprise admins turn Cowork on per group.
  • feature Extend Cowork with third-party MCP platforms (Slack, Sentry, AWS, Atlassian, GitHub, Microsoft 365, etc.) — the stack this digest runs on.
