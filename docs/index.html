v2.1.322 — fast mode on Vertex Tue 10 Nov AEDT · 1 bullet · latest

Vertex Added fast mode on Vertex in the global, us and eu regions, falling back to standard speed if Vertex refuses it. If you run Claude Code through Google Vertex, fast mode (including Fable 5.2 fast mode) now works there; requests degrade to standard speed instead of failing when Vertex declines.

v2.1.321 — Fable 5.2, MCP OAuth secret-leak fix, sandbox and deny-rule fixes Tue 10 Nov AEDT · 118 bullets

model Added Claude Fable 5.2 (claude-fable-5-2), now the default Fable model — 1M context, $8/$40 per Mtok with $0.20/Mtok cache reads. Saved Fable 5.1 picks move to fable: on Pro and Max at once, on Team and Enterprise once your organization allows it.
security fixes Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them. Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt. Fixed Bash permission checks judging a file write from the wrong folder and not prompting; fixed deny rules and protected-file prompts not applying to the file a cp or mv into a directory writes.
Remote Control Added --settings <file> to claude remote-control, applying a settings file to every session it starts; if the file changes, no new session starts until you restart claude remote-control.
reliability Fixed sign-in, token refresh and logout hanging when a middlebox accepts the connection but never completes the TLS handshake; fixed /config showing Manual as default when sessions start in auto mode; fixed claude agents ignoring flags typed before agents; fixed Remote Control showing a false "login expired" in the desktop app.

v2.1.319 and v2.1.318 — previous releases Wed 04 – Fri 06 Nov AEDT · 230 bullets between them

2.1.319 · permission bypass, sandbox escape, auto mode Fixed a Bash permission bypass via a crafted environment prefix, a sandbox escape when creating a worktree, sed skipping the permission check in accept-edits and auto mode. Auto mode behind LLM gateways or with telemetry off no longer falls back to the built-in classifier (CLAUDE_CODE_AUTO_MODE_SERVER=0 keeps it). Added permissions.denyInsteadOfPrompting, MCP tasks in the terminal, CLAUDE_CODE_DISABLE_FEATURE_FLAGS.
2.1.318 · credentials, subagents loginExpiresAt in claude auth status, credential_expires_at in claude -p JSON and a stderr warning 10 days before a stored sign-in ends; assume_role on gateway mantle upstreams; Claude Code no longer installs the IDE extension from an IDE terminal.
2.1.317 and earlier 2.1.317: email-exfiltration check, fail-closed SDK hooks, gateway cost report. 2.1.316: Opus 4.8 fast mode deprecated (removed 30 Nov). 2.1.314: blockWritesOutsideWorkingDirectories. 2.1.311 = stable.

Models

Fable 5.2 fast mode now on Vertex (2.1.322) · Opus 4.8 fast mode removed 30 Nov (18 days; no fallback)

Current lineup and what changed

  • Fable 5.2 claude-fable-5-2 — launched 9 Nov; default Fable model in Claude Code 2.1.321+. 1M context; $8/$40 per Mtok (Fable 5.1 was $10/$50), $0.20/Mtok cache reads; optional fast mode, now also on Vertex from 2.1.322.
  • Mythos 5.2 Same underlying model as Fable 5.2 with fewer cyber/bio safeguards; access via Anthropic's verification programs.
  • launch offer · ends 16 Nov Pro plans and standard Team seats get Fable models included in weekly limits through 16 Nov 11:59 pm PT.
  • Opus 5.5 claude-opus-5-5 — default Opus and the recommended daily driver.
  • Sonnet 5.5 claude-sonnet-5-5 — default Sonnet.
  • Haiku 5.5 claude-haiku-5-5 — default Haiku; 1M context.
  • Opus 4.8 fast mode · removed 30 Nov Fast-mode requests on Opus 4.8 return an error after 30 Nov with no fallback — migrate to Opus 5.5 or Fable 5.2 fast mode.

Security & evals

No new security fixes in 2.1.322 · the 2.1.321 fixes still drive the pin

Today's actionable items

  • upgrade · pin v2.1.322 Move runners, auto-mode pipelines and headless claude -p jobs to 2.1.322 (or at minimum 2.1.321). 2.1.322 adds nothing security-relevant on top of 2.1.321, so a fleet already on 2.1.321 only needs it for Vertex fast mode.
  • MCP OAuth secrets Before 2.1.321, MCP OAuth requests could send refresh tokens to another host on redirect. If you use OAuth-authenticated MCP servers you don't fully control, consider rotating those tokens after upgrading.
  • sandbox and deny rules Read-only Bash outside the sandbox, writes judged from the wrong folder, and cp/mv deny-rule gaps are all fixed in 2.1.321+.
  • Unified Claude is live Since Wed 11 Nov 07:00 AEDT, Desktop policies with no desktopHome open Unified Claude with Cowork on, even where coworkTabEnabled is false. Set desktopHome explicitly if you need the old behaviour.
  • dates 16 Nov: Enterprise unified default on; Fable launch offer ends. 17 Nov: deprecated Desktop keys start warning. 30 Nov: Opus 4.8 fast mode removed; Plugins page reaches Enterprise, and orgs with Skills off also block plugins in Desktop.

Claude Desktop

Unified Claude live since Wed · Plugins page · Fable 5.2 in the picker

What's new

Unified Claude · live since Wed 11 Nov 07:00 AEDT Per Claude Cowork and chat are one Claude: a Desktop policy with no desktopHome opens Unified Claude with Cowork on. Enterprise organizations get it by default from 16 Nov (admin guide).
Plugins page One Plugins page replaces Customize and the separate Skills, Connectors and Plugins tabs (Free/Pro/Max/Ultra/Team now; Enterprise 30 Nov). From 30 Nov, orgs with Skills off also block plugins in Desktop.
Fable 5.2 Available in Claude apps on all paid plans (Enterprise: admin-enabled). Medium effort is the default; Anthropic reports about 55% fewer safety blocks than Fable 5.1 across claude.ai, Claude Code and Cowork. Launch offer includes Fable in Pro and standard Team weekly limits through 16 Nov.
beta · 5–6 Nov Personal Finance (US only; Pro, Max, Ultra) lets users link bank, card, loan and investment accounts; Enterprise orgs can tag projects with cost codes (release notes). Neither is Desktop-specific.

Claude Cowork

Now part of every conversation for unified users

What's new

Cowork in every conversation · since Wed 11 Nov For Desktop policies with no desktopHome, Cowork is now part of every conversation rather than a separate tab. Existing skills and plugins carry over.
Enterprise · plugin scanning (beta) Enterprise plans can enable a beta scanner that checks third-party skills and plugins for malicious content on upload or edit (release notes).
carry-over · cloud tasks New Cowork tasks on Pro, Max and Ultra run in the cloud (since 6 Oct); local file access still needs the desktop app open. MCP tasks backgrounding and denyInsteadOfPrompting (2.1.319) keep unattended scheduled runs from stalling.
